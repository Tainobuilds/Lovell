# Content intake: what we need from Lovell Media

Send everything in one shared folder (Google Drive / Dropbox) using the folder names below.
Where something isn't ready, the site keeps a branded placeholder, so nothing blocks the build.

## 1. Brand
| Item | Format | Notes |
| --- | --- | --- |
| Approved website mockup | PDF / Figma link / PNG | The design reference for the whole site |
| Logo: full wordmark | SVG (plus PNG backup) | White version for black backgrounds |
| Logo: icon / monogram | SVG | Used for the favicon and small spaces |
| Brand guidelines (if any) | PDF | Exact red value, fonts |

## 2. Showreel (homepage hero)
- 30–60 seconds, **no audio needed** (it plays muted)
- MP4 (H.264), 1920×1080, under 8MB. We can compress a larger master.
- Plus one still frame for the poster image (JPG, 1920×1080)

## 3. Services: one visual each
For **OOH, Concerts, Podcasts, Events, Branded Content**:
- 1 hero image (JPG, at least 2400px wide, landscape) **or** a 5–10 second silent loop (MP4)
- Confirm or edit the description and capabilities list (see the site's service pages)
